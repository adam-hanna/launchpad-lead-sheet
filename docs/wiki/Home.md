# Launchpad Lead Sheet

A browser companion for Ableton Live: it follows Live over MIDI clock and lights a Launchpad Pro MK3 with
the current bar's key and chord tones. No Max for Live, no Remote Script.

- **[Setup](Setup)** — IAC buses, Live preferences, track routing, first connection (ten minutes).
- **[Troubleshooting](Troubleshooting)** — stuck notes, the device stuck in Programmer mode, the
  conflict state, two tabs.
- **[Protocol](Protocol)** — Launchpad Pro MK3 SysEx cheat sheet.

Source, issues and roadmap: the repository. Behaviour is specified in `docs/plan.md`; the wiki is
published from `docs/` by `scripts/publish-wiki.sh`, so edit there, not here.
